# efeito-carrossel

Carrossel de imagens de carros com indicadores e interação em JavaScript.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Página principal em `index.html`; estilos em `css/style.css`; interação em `js/script.js`.

**Tecnologias:** `CSS`, `HTML`, `JavaScript`.

## Visualizar localmente

Use um servidor HTTP local para abrir `index.html`.
